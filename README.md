# utanoteapp.com

The Uta Note website, served by GitHub Pages: a landing page plus the Privacy Policy (`/privacy/`) and Terms (`/terms/`).

Don't edit these files by hand. They're generated from the Uta Note app repo (`docs/alpha/privacy-policy.md`, `docs/alpha/terms.md`) by its `scripts/render-site.mjs`:

```sh
cd ../UtaNote && node scripts/render-site.mjs ../utanote-site
```

Then commit and push here.
